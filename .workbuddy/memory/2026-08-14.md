# 2026-08-14

## 网页设计评审（basic-korean-web）
对韩语学习站做了设计层面评审，关键发现：

### P0（可用性/可读性）
- 主色 `#c46a29` 上白字对比度仅 ~3.86:1，低于 WCAG AA 4.5（导航 active、AI 提交按钮等小字不达标）。
- 入场动效在 Vue 主干路径完全失效：`navigate()` 的 Vue 分支(约 851 行)早返回，从不在 `main` 加 `page-enter`；`initRevealObserver` 观察的 `.reveal` 类“预留未使用”。线上页面切换无过渡，整段动画 CSS 成死代码。
  - 修复方向：vue-app 用 `<transition name="page">` 包裹 `<component>`，或 Vue 分支主动加/去 `page-enter`。

### P1（响应式/交互）
- 769–1000px 区间：`.nav` 被 `min-width:769px{display:flex!important}` 强制横排，8 个导航项+按钮会溢出。
- 移动端菜单：仅切 `.show`，无 ☰/✕ 图标切换、无点外部/Esc 关闭、滚动穿透。
- 360px 小屏 header 偏挤（logo+badge+主题+统计+登录+汉堡）。

### P2（一致性/打磨）
- `.badge-blue`/`.badge-purple` 实为同款橙，命名误导。
- `.level-badge-optional` (#9e9e9e on #f5f5f5) 对比度 ~2.5:1 几乎不可读。
- `.nav`/`.nav.show` 在两段 `max-width:768px` 媒体查询里重复定义（绝对定位 vs flex-wrap），逻辑纠缠。
- 词性色块亮/暗两套硬编码，增删词性需改 CSS+JS 两处。

设计系统整体优点：CSS 变量统一、暖铜奶油主题有辨识度、暗色模式完善、字体回退合理、有 focus-visible/reduced-motion/iOS safe-area。
