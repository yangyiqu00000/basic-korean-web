## 1. 设计 Token 基线（css/style.css `:root` 实值）

### 1.1 主色三分（最高优先级契约）

| Token | 实值 | 用途 | 违规示例 |
|---|---|---|---|
| `--primary` | `#af5e25`（暗色下为亮橙） | **填充/背景**，其上放白字 4.72:1 | 拿它当浅底上的文字色 |
| `--on-primary` | 亮色 `#ffffff` / 暗色深棕 | 压在 `--primary` 填充上的前景色 | 用在非主色填充上 |
| `--primary-ink` | `#a0501c` | 主色系**文字落浅底**专用（5.25–5.54:1） | 用作填充色 |
| `--accent` | `#e28c51` | **只作边框/装饰**（文字对比仅 2.37:1，被 contrast 门拦截） | 作文字色 |

### 1.2 中性色与语义色

| Token | 实值 |
|---|---|
| `--bg` / `--card-bg` | `#f6f6f5` / `#fbfbfa` |
| `--text` / `--text-light` | `#1f1b17` / `#6d635a` |
| `--border` | `#e4ddd4` |
| `--success` / `--warning` / `--error` | `#21825f` / `#d4731a` / `#d0573a` |
| `--header-bg` | `rgba(246,246,245,0.72)`（移动端抽屉方案下 `.header` 已 `backdrop-filter:none`，勿在媒体块外改回） |

### 1.3 阶梯

- **间距**：`--space-xs/sm/md/lg/xl/2xl/3xl` = 4/8/16/24/32/48/64px，新布局禁止引入阶梯外的 magic number（1px 边框、组件内部 6px 级微调可豁免，须在迭代记录注明）。
- **圆角**：`--radius: 20px`（卡片）/ `--radius-sm: 12px`（按钮/小件）；胶囊用 `border-radius: 99px`（如 `.review-track`）。
- **字号**：`--text-xs→3xl` = 0.75/0.875/1/1.125/1.25/1.5/2rem。
- **动效时长**：fast 150ms / base 250ms / slow 400ms，缓动统一 `--ease`；抽屉等位移动画用专用 cubic-bezier `cubic-bezier(0.22,0.61,0.36,1)` 属合法特例。
- **阴影**：`--shadow` / `--shadow-hover`，新卡片优先复用，不自造。

## 2. 布局范式基线

- **z-index 层级表**（本轮 WIP 已定，改动须整体复核）：
  - `.header` = 1001（移动端纯色顶栏，`backdrop-filter:none`）
  - `.nav-backdrop`（抽屉遮罩）= 999，`rgba(0,0,0,0.42)`，`opacity` 过渡 0.25s
  - 抽屉 `.nav` 在 header 的 stacking context **内部** z-index=1，宽度 `min(78vw, 300px)`；顶栏按钮（`.logo/.mobile-menu-btn/.theme-toggle/.stats-toggle/.auth-toggle`）在 context 内 z-index=2 保证可点
- **移动溢出**：`max-width:768px` 下 `html, body { overflow-x: clip }`（不是 hidden——hidden 会创建滚动容器）。验收口径：`documentElement.scrollWidth <= innerWidth + 1`。
- **抽屉显隐**：`visibility` 双阶段过渡（关闭延迟到滑出动画播完），仅 `translateX(100%)` 不够（fixed 元素仍扩展 scrollable overflow）。
- **响应断点**：375 / 480 / 600 / 769（`test:viewport` 的口径）；375px 下顶栏为极限宽度——`.logo-text` 缩到 15px、`.logo-badge` 隐藏，不得往顶栏加第 5 个按钮。
- **入场动效**：统一 `.main.page-enter`，只经 `retriggerPageEnter()` 触发。
- **reduced-motion**：所有新增 keyframes 动画（如 `review-flow`）必须配 `@media (prefers-reduced-motion: reduce)` 关停。

## 3. 交互范式基线

| 范式 | 实现 | 规则 |
|---|---|---|
| 破坏性确认 | `bkConfirm` 确认框（`openBkConfirm`/`bkConfirmOk`） | 删除/清空必须走它，不用原生 confirm；ESC 关闭 |
| 移动抽屉 | `toggleMobileMenu`/`closeMobileDrawer` + `navBackdrop` | 关闭四途径收敛：再点汉堡 / 遮罩 / ESC / `navigate()`；`aria-expanded` 必须同步 |
| Toast | 现有 toast 机制 | 同步层（SyncLayer）错误**不弹** Toast，只 `console.warn` 带 `[sync]` 前缀 |
| 空态 | `.scene-empty` 样式 + 引导按钮 | 空列表必须给下一步动作的出口（如「去临境创建」） |
| 进度反馈 | `.review-progress`（`role=progressbar` + aria-valuenow/min/max） | 纯装饰动画可省略，语义进度必须有 ARIA；百分比 clamp 0–100，total=0 给 0% 不做除法 |
| 词性色 | `ELEM_COLORS` + `elem-*` class，7 类（词干/助词/终结/连接/时态/否定/语气） | 两套解析函数（`getElemClassFromMeaning` / `getElemClass`）改一同步二 |

## 4. 代码范式基线

- 渲染函数返回**字符串拼接 HTML**（非模板/DOM API），用户或 AI 数据一律 `escapeHtml()` 包裹后再拼。
- 持久化写入口统一走 app.js 的 `setItem`（内部已接 `syncPut` 上云）；新增纯本地键须在 AGENTS.md 持久化小节登记。
- 记账口径：统计类计数只加在用户明确意图的函数（如 `reviewMark()`），浏览/翻页类函数（如 `nextWordCard()`）刻意不记。
- 组件 = Vue 薄壳：`v-html` 转发全局 `renderXxx()`，Vue 只管路由与 `:key` 重建；不引入真正的组件化、不引入框架。
- 新增 E2E 断言：优先加进 `tests/e2e/self-check.js`（交互流程段）或 `tests/e2e/ci-run.js`，跟随项目「事故 → 防复发门」的惯例。
